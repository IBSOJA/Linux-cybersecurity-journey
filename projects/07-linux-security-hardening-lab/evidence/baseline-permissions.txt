Account Home Directory Investigation
------------------------------------

The accounts A and Alice have the following home directory
paths recorded in /etc/passwd:

A: /home/A
Alice: /home/Alice

Neither /home/A nor /home/Alice currently exists.

A and Alice have locked passwords and have never logged in
according to the baseline user assessment.

A search of /home found no files owned by A or Alice.

Developer Group
---------------

Developers:x:1005:Alice,bob

Alice and bob are members of the Developers group.

Assessment
----------

The permissions of the primary account database files are
appropriately restricted for the current baseline.

The /etc/shadow and /etc/gshadow files are not world-readable.

The existing user home directories have restrictive 750
permissions, preventing access by users outside the owner
and group.

No permission changes were made during the baseline
assessment.
